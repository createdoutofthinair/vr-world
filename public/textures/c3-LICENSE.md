- Asset pages, actual download URLs and file hashes: `c3-sources.json`.

These are the provider's flat color maps used by its tiling preview, not images of shaded material spheres. The original ZIP endpoint was unavailable in the build environment. The official tiling maps are covered by the same CC0 license. Bundled copies are resized to 1024-pixel JPEGs for page delivery. The app converts them to 512-pixel neutral-luminance PNGs, with architectural and biome colors assigned separately. Export archives contain the actual derived PNGs and source notices.

The rest of the material patterns, leaf geometry and leaf textures are generated by c3 code. This notice does not apply a license to the project code or to user uploads.
