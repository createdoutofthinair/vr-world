## Recovered 0.5 checkpoint

Recovered the unpublished working changes from the interrupted conversation into an isolated checkout based on `db1b7cd`, without changing that conversation's working tree. Scope includes the three-block elevated road recipe with 12% maximum approach grade, support/crossing/entrance exclusions, terrain integration and editor controls; park density/foliage and creek fixes; actual PNG alpha classification; repaired native calibration dependencies; and optional embedded-texture GLB export.

GLB is a static authored snapshot in right-handed metres. It preserves node placements, shared geometry, physical UV scale, diffuse/normal/emissive maps and packed roughness/metalness maps, and converts DirectX normal conventions. Actions and collision are metadata, not glTF animation or physics. Independent binary fixtures check header/chunk alignment, geometry/index payload, UVs, material channels, alpha modes, embedded image bytes and selected scope. The emitted RWX viaduct fixture checks the actual reconstructed approach walk as well as bounds and supports. GLB now also passes the independent Khronos validator with asymmetric, PBR and cutout fixtures. UV handedness is preserved and browser image orientation is baked into PNG rows, retaining the tangent basis. External viewer visual validation remains open. Thin viaduct guardrails use solid collision rather than walkable-surface metadata, with a lateral between-post regression. Updated neighborhood and viaduct software previews were inspected and published with per-file generator/hash evidence. The viaduct scene contains 7,274 pieces / 251,410 triangles; no measured GPU performance is inferred.

This checkpoint has no new browser/GPU or native VP evidence. The full plan remains incomplete.

## Important limits and remaining implementation

1. General polygonal room graphs, per-unit/per-facade overrides and arbitrary footprints remain unfinished. Rectangular authored boundaries now derive shared walls and connections from one source; a physical grid checks routes from entrances/stair landings with openable leaves excluded. Autogenerated room layouts are limited to rectangular buildings; room-by-room manual layouts can be validated against connected wings. Kennedy House remains reference-pending.
2. Curved streets, editable road graph, arbitrary viaduct authoring and large-world streaming are missing. A bounded three-block viaduct recipe now provides graded approaches, underpass clearance, grounded supports and rails. Current city is a bounded regular neighborhood.
3. Per-species custom recipes, editable attraction envelopes, biome masks and ecological succession are unfinished. Pruning controls are global woody-family controls with per-pin recipe snapshots. Pins currently edit position, seed, scale and growth locking; crown/trunk guide editing remains unfinished.
4. Continuous sculpt brushes, surface-layer smoothing, geological region editing, overhang meshes and surface-specific cliff bakes remain unfinished. Terrain is a heightfield with explicit boundary sides.
5. LOD/streaming, rich dimensioned plan annotation, verified target budget gates, complete accessibility/help and full usability acceptance remain unfinished. Economy plants are a saved recipe choice, not runtime LOD.
6. Hosted group anchors/nesting and editable arbitrary group imports are missing. Experimental AWG3 output is a probe, not a verified native adapter. No current hard group radius/count is claimed.
7. Candidate RPM rotate is disabled by default. Native rotation/pivot/defaults, animation grammar and moving-solid collision are unverified/unfinished. Generated motion is nonsolid; preview door interactions export only saved static poses.
8. The five bundled ambientCG CC0 color sources retain their URLs, source/derived hashes and modification notices. PBR uploads are preserved but classic RWX exports only the supported diffuse/profile subset. User uploads stay local until the user downloads or hosts a package.
